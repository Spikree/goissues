## This project attempts to solve a problem which arises when trasfering GitHub repos to another provider
- The problem we face : 
  - When mrigating projects everyting gets migrated like the commits and everything
  - But the issues are not migrated

-> This project tries to solve this problem by saving all the issues and comments in your repostory rather than on github
-> Currently the project is in its developement phase and I have not decided the architecture yet
-> currently the issues are saved in a .md file I intend to change it so it stores it on the git tree
